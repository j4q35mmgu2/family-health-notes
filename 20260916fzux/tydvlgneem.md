# 冬季高发！这种又寒又热的“寒包火”感冒，家长最怕，该拿它怎么办？

> 更新时间：2026-09-16 (UTC+8)

天气一转冷，体质娇弱的孩子就很容易来医院“报道”——稍不注意，孩子又被外感缠上了。
有跟着一起学习中医育儿知识的家长还会自行辨证，希望能通过自己的经验储备，把孩子不那么严重的小病居家调治好。这个时候就要先辨证。
孩子感冒咳嗽，流清鼻涕，畏寒怕冷，往往是风寒外感。孩子喉咙红肿疼痛，流黄稠鼻涕，往往是风热外感。
这都比较好辨证。但少数情况下，家长会发现，孩子既有风寒受寒的症状，也有一些“热气上火”的特征，一时间就有些手忙脚乱、束手无策。
这种情况该怎么处理呢？不知各位家长有没有听过“寒包火”这个词。

**1**

**“寒包火”=风寒+内热**

什么是**“寒包火”**？我们根据字面意思理解，就是外面是寒，内里有热，寒包裹着热。
当孩子有内热，又不慎外感风寒时，寒邪束缚在体表，导致体内的“热气”不能向外宣散，“热气”被体表的寒邪“包裹”起来了。
这种情况下引起的感冒咳嗽，就称为“寒包火”。
“寒包火”是兼有外寒和内热，因此会表现为：
** 既有恶寒、体痛、咳嗽、清涕、鼻塞等表寒现象；******** 又有口干口渴、咽喉干痛、咳嗽少痰、小便短赤、舌红苔黄、大便干燥等里热现象；******除此之外，部分孩子还可能会出现高热、头痛、全身关节肌肉酸痛等症状。

**2**

**不同的“火”**

**要用不同的解决办法**

家长别急，“寒包火”的本质是体有郁热、外感寒邪，所以调理的大方向是**散表寒、清内热。**
孩子上火，分为实火和虚火，所以寒包火的调理，也要分两种情况讨论：
**①  外寒 + 实热：散表寒 + 清内热**
如果孩子体内的是实火，则会表现出：**舌红、苔厚发黄，口气大，大便硬结，小便赤黄，如果发热，多为高热。**
孩子有实火，往往是积食化热引起的。初期时，可以先用**生姜红糖水**为孩子祛风散寒，并用**独脚金瘦肉汤**消积清热。
**▶ 推荐用药：防风通圣散。**

**许尤佳育儿堂·食疗方**

**生姜红糖水**

**材料：**生姜5g，红糖适量、白葱头3个。
**做法：**2碗水下锅，水沸后放入白葱头和生姜煮15分钟，加入红砂糖适量调味即可。视情况连用1～3天。
**功效：**祛风散寒。
**适用年龄：**3岁以上对证、少量多次分服。蚕豆病可服。

**许尤佳育儿堂·食疗方**

**独脚金瘦肉汤**

**材料：**独脚金3g，猪瘦肉50g。
**做法：**独脚金洗净，猪瘦肉焯水；锅中加约3碗水，煮沸后放入所有材料，小火煲1.5小时后即可调味温服。独脚金性寒，注意连服不超3天。
**功效：**消积清热而不伤正气，适合积滞化热、食欲不振的孩子服用。
**适用年龄：**3岁以上对证、少量多次分服。蚕豆病可服。

**② 外寒 + 虚热：散表寒 + 滋阴生津**
如果孩子体内的是虚火，则会表现为：**舌红、少苔、少津；口燥咽干；手足心热；如果发热，多为低热；全身湿热明显；反复口腔溃疡、麦粒肿。**
如果孩子属于外寒 + 虚热，则调理的思路为散表寒，再滋阴补充津液，可用**乌梅白糖汤**。

**许尤佳育儿堂·食疗方**

**乌梅白糖汤**

**材料：**乌梅5颗，白糖10g。
**做法：**乌梅和白糖同时下锅，加3~4碗水煲至乌梅软烂（约40分钟）即可。
**功效：**生津止渴，健脾。
**适用年龄：**3岁以上对证、少量多次分服。蚕豆病可服。

除了食疗方，**“寒包火”在用药上，**也可以这样选择：
① 风寒+积热实热：**藿香正气口服液（无酒精），**或**防风通圣散。**
针对孩子的积食情况，还可以考虑使用新三星汤（麦芽山楂固体饮料），这个经典的“明星”消积方也是寒温并用，而且选材药食同源，全年龄适用，只要孩子有积食，或预防积食，都能使用。**
****想给孩子的脾胃健康囤货的家长，可以关注文末的“消积驱寒”特惠套装。**
②  风寒+虚火，或实在分不清孩子的内热是实热还是虚热：**通宣理肺丸。**

**3**

**针对“寒包火”咳嗽**

**用好2碗止咳汤**

**“寒包热，热郁肺俞，遇秋冬寒凉辄发咳，寸脉坚，声音窒。”****——《类证治裁》卷二**
孩子“寒包火”，往往会咳嗽不停。对于这种咳嗽，想要缓解这种咳嗽，除了前面针对病证本身的用药食疗之外，还可以用**二前汤。**
这个止咳方的好处在于，它对缓解外感咳嗽的功效比较好，而且家长用起来不用仔细辨证寒热，尤其适合刚入门中医育儿的“小白”家长。

**许尤佳育儿堂·食疗方**

**二前汤**

**材料：**白前8g，前胡8g。
**做法：**材料下锅（不可用铁锅、铜锅），加约1碗半水，浸泡半小时后，大火煮沸，转小火煲约一碗即可。每日2次，连服3天，早晚饭后温服。
**功效：**降气化痰，宣肺止咳。
**适用年龄：**2岁以上对证、少量多次分服。蚕豆病可服。
