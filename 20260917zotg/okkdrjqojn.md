# 【科普】腰酸、腿软、抱娃没力？不一定只是累的

> 更新时间：2026-09-17 (UTC+8)

生完娃后，您是不是经常觉得腰酸背痛？抱一会儿宝宝就直不起腰？夜里翻身膝盖还“咯吱”响？老人们常说“生个孩子掉颗牙”。其实，掉的可能不止是牙，还有您的“骨气”。

**PART 0****1****为什么产后会“丢骨气”？**

怀孕和哺乳对妈妈的骨骼来说，是一场长达一年多的“钙质大迁徙”。

1. 孕期：胎儿发育需要大量钙，主要来自妈妈

2. 哺乳期：每天通过乳汁流失约200-300mg钙

3. 雌激素波动：孕期孕妈妈体内雌激素水平的变化会影响骨代谢，加速骨量流失

4. 生活习惯：坐月子出门少→晒不到太阳→维生素D缺乏；活动量减少→骨骼缺乏刺激→骨量加速流失；饮食习惯难改变→高盐高脂饮食→影响钙吸收

5. 补钙不足，身体“拆东墙补西墙”——从骨骼中调取钙，从而满足宝宝需求

妈妈的骨密度，就这样悄悄下降了。

**PART 0****2****产后哪些妈妈容易“丢骨气”？**

1. 哺乳超过6个月的妈妈

2. 孕期就有明显腿抽筋、腰酸背痛

3. 产后一直腰酸背痛、膝盖发软

4. 双胞胎或多胞胎妈妈

5. 孕期很少喝奶、很少晒太阳

其实，腰酸腿软有时并不是“带娃累”，而是骨量悄悄流失，在产后的骨量告急。产后42天骨密度检测可以及时了解自己的骨质状况，必要时进行干预处理，让自己的骨质更健康。
