# 体内湿气重影响怀孕吗 体内湿气重该怎么办

体内湿气重影响怀孕吗 体内湿气重该怎么办更新时间:2017-05-01

女性湿气重是非常普遍的现象，很多年轻女性因为平时生活习惯差，天长月久，体内湿气越积越多。时间长了，虽然不足以威胁生命，但是对身体健康也造成一定影响。对于备孕的女性来说，最关心的问题还是湿气重是否会影响。毕竟一个女人要是连孩子都怀不上，那可就真的麻烦大了。那么，到底体内湿气重影响怀孕吗?

体内湿气重影响怀孕吗

体内湿气重是会影响怀孕的，因此如果湿气重还想怀孕那就需要进行调理，可以用胃苓汤、香砂六君子汤等等中药调理，最好去做个检查看是不是有感染的情况，如果感染还需要抗真菌治疗，平时养成良好的习惯，把湿气调理好之后再要宝宝。

体内湿气重该怎么办

1. 中医调理

找信誉好的医生看看，开几幅中药进行调理，中药虽然见效慢，但是对身体伤害很小，如何再结合其他方面进行调理，事半功倍。不过注意一定要去正规的大医院，不然可能会被一些庸医看成多囊症，耽误治疗。

2. 多运动出汗

有氧运动配合力量训练，除湿的同时有强健体魄。运动乃除湿良方，每天坚持跑步半小时，半年过后不但湿气除了，人都要神清气爽许多。那些扭扭捏捏的动作就算了，一定要有氧运动才行。

3. 禁食刺激食物

不要吃辛辣刺激性食品，葱姜蒜要适量。平时不要喝酒、抽烟，不然会加重体内湿气。

4. 不要熬夜

这也是最重要的一点，一定不要熬夜，宁愿早起也不要熬夜。很多年轻女性不抽烟不喝酒，平时也没什么不良嗜好，但就是湿气重，其实就是熬夜在搞鬼。

5. 避开湿热环境

涉水及淋雨后应及时将身体擦干并更衣;阴天水凉时不要在河水及游泳池里长时间浸泡，以防外湿入侵肌表伤人。

6. 拔罐

拔罐祛湿并不是说一次两次就可以了，也是要按疗程来进行治疗的。拔罐疗法是传统中医常用的一种治疗疾病的方法，这种疗法可以逐寒祛湿、疏通经络、祛除瘀滞、行气活血、消肿止痛，具有调整人体的阴阳平衡，解除的功能，从而达到扶正祛邪，治愈疾病的目的。

另外要特别提醒的是，拔罐要去正规场所进行，近年来由于拔罐不当造成的伤害的新闻可不少，大家要特别注意了。
